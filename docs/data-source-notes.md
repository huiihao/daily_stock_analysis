# 数据源实测笔记（本 fork 特有）

> 本文记录本部署环境下各数据源的**实际可用性**，与上游 `data-source-stability.md`
> 描述的理论降级链有出入 —— 因为很多源在实际网络环境下已被封禁或权限不足。
> 最后更新：2026-11-05

## 一、A 股数据源全景与定位

| 数据平台 | 授权模式 | 核心特点 | 本项目中的定位 |
|---|---|---|---|
| **AKShare** | 免费开源 | 覆盖最全的爬虫库（A股/ETF/期货/宏观/另类） | 主力兜底源，但**本质是爬虫**，上游接口变更或封禁就会失效 |
| **BaoStock** | 免费开源 | 免登录免积分，日线/5分钟线/历史 PIT 财报，时序稳定 | **最适合做日K主源** —— 协议稳定，不像网页爬虫容易被封 |
| **PyTDX** | 免费开源 | 通达信协议直连，当日 Tick / 分时 | 盘中实时监控；本项目仅作降级候选 |
| **TuShare Pro** | 积分制 | 接口规整、字段丰富、成分股变迁 | 需 2000 积分才有基础接口权限，**当前 token 全接口无权限** |
| RQData / JoinQuant | 商业授权 | 买方级清洗、严格 PIT | 个人部署不现实 |
| Wind / Choice / iFinD | 机构终端 | 事实标准 | 个人部署不现实 |

## 二、本环境的实测结果

| 数据需求 | 首选 | 实际可用 | 备注 |
|---|---|---|---|
| 全市场快照 | 东财 `stock_zh_a_spot_em` | ❌ 封禁 → **新浪 `stock_zh_a_spot`** | 新浪约 22-60 秒、5571 只，**但只有价量字段，无 PE/PB/换手率** |
| 个股日K | TuShare → Efinance | ❌ 无权限 / ❌ 连接失败 → **AkShare** | 可考虑改以 BaoStock 为主源（见下） |
| 个股实时 | Tencent | ✅ 可用 | |
| 申万行业映射 | AkShare 申万接口 | ✅ 可用但**限流严格**（连续约 30 次调用后拦截） | 已改为静态文件，月级刷新 |
| 大盘复盘 | TickFlow | ⚠️ 无标的池权限 → AkShare 新浪链 | 放宽超时到 90s 后才拿到市场宽度 |
| 新闻搜索 | Bocha | ❌ 余额不足 → **Tavily** | Tavily 实测可用 |
| TickFlow | — | ⚠️ 个股行情可用，**无标的池批量报价权限** | 无法用于市场宽度 |
| TuShare | — | ❌ 全部接口 `40203 无权限` | 积分不足，当前等同禁用 |

## 三、结论与待办

1. **BaoStock 值得升为日K主源**：免登录、免积分、协议稳定，不受网页接口封禁影响。
   已本地实测 `baostock.query_history_k_data_plus()` 正常返回。
2. **东财系接口已整体不可用**：`clist/get` 对本地与 GitHub runner 的 IP 均持久封禁，
   依赖东财的字段（量比/换手率/PE/PB）需另寻来源。
3. **估值因子**目前取自行业映射文件（月级陈旧度），若需要日频估值，
   BaoStock 的 PIT 财报或 TuShare（补足积分后）是可行方向。
4. **GitHub Actions 定时任务在仓库长期无提交时会被自动暂停** ——
   2026-10-14 起全部定时工作流停摆，需保持仓库有提交活动，或改用外部触发。
